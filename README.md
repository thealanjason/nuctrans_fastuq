# nuctrans_fastuq

Surrogate-based uncertainty quantification.

```bash
pip install git+https://github.com/thealanjason/nuctrans_fastuq.git
```

The Gaussian process surrogates need the extra dependencies: `pip install ".[gp]"`.

The folder `src/nuctrans_fastuq/bayesvalidrox/` is a copy of [BayesValidRox](https://doi.org/10.18419/DARUS-4752) and keeps its own MIT license (`LICENCE.md`).
